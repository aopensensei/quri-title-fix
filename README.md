# Quri Title Fix

Quri（`quri.omnicamp.us`）の教材タイルで省略される資料タイトルを、複数行で表示しやすくする非公式ブックマークレットです。

## 使い方

1. [配布ページ](https://YOUR_GITHUB_USERNAME.github.io/quri-title-fix/) を開く（公開後、URLを修正してください）。
2. 「Quri タイトル全文表示」のリンクをChromeのブックマークバーにドラッグして登録します。
3. Quriにログインし、教材が並んだ講義ページを開きます。
4. 登録したブックマークをクリックして表示を補正します。再度クリックすると解除します。

ドラッグで登録できない場合は、`quri-bookmarklet.txt` の内容をコピーし、ブックマークのURL欄に貼り付けてください。

## 対応範囲

- 対象ホスト: `quri.omnicamp.us` のみ
- PDF、Notebook、外部リンク等の資料カードを文字列で検出
- ページ読み込み後に手動実行が必要（画面遷移後も再実行する場合があります）
- Quriの仕様変更により、動作しなくなる可能性があります

## 処理とプライバシー

- 既存のカード要素にCSSクラスを付け、表示補正用スタイルを挿入します
- ブックマークレット自体は外部サーバーとの通信、個人情報の送信、教材のダウンロードを行いません
- Quri公式の機能ではありません

## ファイル

- `index.html`: ブックマーク登録用の配布ページ
- `quri-bookmarklet.txt`: ブックマークURLに貼り付ける文字列
- `quri-title-fix.js`: 読みやすいJavaScriptソース
